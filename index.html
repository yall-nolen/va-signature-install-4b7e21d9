Victory Aero: Signature Install

How to use this page. Find your row below. Click Copy: New Message and paste it in as your default signature for new emails. Click Copy: Reply and paste that in as your signature for replies and forwards.
  1. In Gmail, click the gear (top right), then See all settings. Scroll to Signature.
  2. Click Create new, name it Victory - New Message, click in the box, paste.
  3. Click Create new again, name it Victory - Reply, click Reply below, paste.
  4. Under Signature defaults, set FOR NEW EMAILS USE to New Message and ON REPLY/FORWARD USE to Reply.
  5. Scroll down and click Save Changes.
